Phishing Tactical Patterns & Vector Knowledgebase

Technical explanations of common URL obfuscation and credential harvesting vectors.

IDN Homograph & Typosquatting

Attackers use lookalike Cyrillic/Greek unicode characters (e.g. pаypаl.com with Cyrillic 'а') or subtle misspellings (e.g. paypaI.com with uppercase 'i') to deceive users into viewing fake login pages.

Feature: homographRisk, prefixSuffixDash

Raw IP Address Hosting

Phishers often bypass domain reputation filters by serving phishing landers directly via raw IPv4 or IPv6 addresses (e.g. http://192.168.1.1/login), bypassing DNS name lookups.

Feature: hasIpAddress

Subdomain Stacking & Brand Masking

Inserting legitimate brand names in subdomains (e.g. paypal.com.account-verify.xyz) tricks victims into reading the left portion while the actual domain resides on the right.

Feature: subdomainDepth, brandImpersonation

URL Shortener Obfuscation

Using URL shortener services (Bitly, TinyURL, Is.gd) conceals the ultimate landing destination from standard link previews and email gateway scanners.

Feature: urlShortener

Credential Baiting Keywords

Phishing URLs disproportionately contain high-urgency keywords such as verify, login, update, secure, banking, and account in the path or parameter string.

Feature: sensitiveKeywordsCount

High Shannon Entropy Strings

Randomized domain names generated via Domain Generation Algorithms (DGA) display elevated character entropy compared to standard human-readable brand names.

Feature: shannonEntropy
